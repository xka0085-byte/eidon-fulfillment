# 上品信息清单 — 每个商品需要准备什么

> 给我下面这些信息（中英混着发都行，格式随意：微信文字、Excel、截图都可以），我直接把它变成网站上的商品页。

---

## 一、必填：商品基本信息

| 字段 | 说明 | 示例 |
|---|---|---|
| **英文商品名** | 客户看到的标题，别超过 6 个词 | `Hand-Carved Leather Paw Tag` |
| **商品 ID** | 小写英文+连字符，全站唯一，不改 | `leather-paw-tag` |
| **分类** | 三选一 | `custom` / `decor` / `daily` |
| **售价 (USD)** | 含运费的一口价 | `$89.00` |
| **徽章**（可选） | 顶上那个角标 | `New` / `Best seller` / `Ships empty` |
| **库存** | 有货 / 售罄 | `有货` |

## 二、必填：文案（英文，中文我可以翻）

| 字段 | 要求 | 示例 |
|---|---|---|
| **一句话卖点** | ≤ 8 个词，戳心 | `The print they actually left.` |
| **描述** | 2-3 句，说清"是什么+给谁+怎么下单" | — |
| **卖点 4 条** | 每条 = 短标题 + 一句解释 | `316L stainless steel` + `Hypoallergenic, water-resistant, no flaking plating.` |
| **规格 4-5 行** | 材质 / 尺寸 / 重量 / 包装 / 交期 | `Material: 316L stainless steel` |

## 三、必填：图片（这是转化率的关键）

每个商品 **至少 3 张，最好 5 张**：

1. **主图** — 1:1 正方形，干净背景（白/米色），商品占画面 70%+
2. **细节图** — 特写材质/刻字/工艺
3. **场景图** — 戴在身上 / 挂在包上 / 摆在家里
4. **包装图** — 礼盒/开箱（定制类一定要有）
5. **尺寸对比图** — 放在手里或硬币旁边（**这条能直接减少退款**，silvercut 差评里"比预期小"是重灾区）

**图片规格**：
- 尺寸 1200×1200 或更大，JPEG
- 单张 ≤ 300KB（原图发我也行，我来压）
- **无水印、无文字、无"AI生成"字样**
- 不要纯白背景的截图，要有实物质感

## 四、内部信息（不上站，但下单要用）

- 1688 / 供应商链接
- 采购成本（¥）
- 发货方式（云途挂号 / 直发 / 云仓）
- **制作周期**（几个工作日）
- 起订量 / 是否支持一件代发
- 是否支持打样

> ⚠️ **重要：制作周期必须告诉我**。定制类如果实际要 20 天，网站上的"10-15 天"就得改，否则客户投诉会集中在这。

## 五、我收到后会做的合规检查

- 是否涉及品牌/IP 侵权（不能出现任何卡通形象、运动品牌 logo）
- 是否物流敏感（电池、液体、粉末、磁铁）
- 尺寸/重量是否超出云途限制
- 是否与现有 SKU 冲突

## 七、上品优先级建议（按"好卖程度"排）

| 优先级 | 商品 | 理由 |
|---|---|---|
| 🥇 | **手工皮雕肖像吊牌** | 欧美几乎空白、高溢价（$89-129）、不怕物流 |
| 🥇 | **划痕立体画** | 需求已验证（海外客户在找）、客单 $149+ |
| 🥈 | **刺绣肖像挂画/挂件** | 轻、不易碎、中国产业带成熟 |
| 🥈 | **刻字宠物名牌 / 定制项圈** | 高频复购、决策快、价格低好起量 |
| 🥉 | **多层亚克力立体画 / 软陶公仔** | 差异化够，但运费/破损要算清楚 |

**先上 3-5 个 SKU 跑通再扩**，别一次上 20 个——每个 SKU 都要主图、详情、FAQ、QC 流程，铺太宽每个都做不精。
