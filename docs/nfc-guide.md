# NFC 数字纪念页 — 使用指南

## 这是什么
每件纪念品里放一枚 NFC 标签。客户用手机碰一下，就打开一个属于这只宠物的纪念页：
名字、日期、你写给 ta 的一句话。**信息全部编在网址里，不需要服务器、不需要数据库、不需要联网后台。**

## 三个文件
| 文件 | 作用 |
|---|---|
| `site/p.html` | 纪念页本体（已上线，`noindex` 不被搜索引擎收录） |
| `growth/NFC标签写入助手.html` | **本地工具**：填宠物信息 → 自动生成网址（双击打开即可用） |
| `site/assets/nav.js` | 移动端导航（与本功能无关，同期上线） |

## 工作流程（每单 1 分钟）
1. 打开 `NFC标签写入助手.html`（双击）
2. 填：宠物名字（必填）、日期、一句话、署名
3. 点「复制网址」→ 点「预览效果」确认显示正常
4. 手机打开 **NFC Tools** App → 写 → 添加记录 → URL → 粘贴 → 写 → 贴住标签
5. 发货前用另一台手机碰一下测试

## 写标签的具体步骤（NFC Tools）
1. App Store / 应用商店搜 **NFC Tools**（免费，NXP 官方推荐）
2. 打开 → 底部选 **写 / WRITE**
3. **添加记录 / Add a record** → 选 **URL / URI**
4. 粘贴网址 → 确定
5. 点 **写 / Write** → 把手机背面贴住标签（iPhone 是靠近顶部）
6. 提示成功后，用另一台手机碰一下验证

## ⚠️ 注意事项
- **不要锁标签**（NFC Tools 里的 Lock 是永久性的，锁了改不了）。至少先发 20 单确认流程再考虑。
- **网址长度**：助手会显示实时字符数，超过 400 就要精简（NTAG215 标签容量 504 字节）。
- **隐私**：`p.html` 已设 `noindex`，不会被搜索引擎收录。但**拿到链接的人都能看**——所以别在网址里写全名、地址、电话。
- **承诺克制**：跟客户说"这个页面跟着标签走，只要标签还在、EveryBeloved 还在，它就一直在"，不要说"永久保存"。

## 采购
- 1688 搜 **NFC贴纸 NTAG215**（504 字节，够用）
- 圆形 25mm / 30mm、带背胶的最实用，批量 **¥1-3/枚**
- 买回先试写一张，确认能打开再批量

## 放置位置（按客户体验排序）
1. **礼盒内盖** —— 客户打开盒子就能碰
2. **随单卡片背面** —— 卡片正面印 "Tap your phone here"
3. **吊坠包装袋内侧**

## 之后可以升级的方向
现在是"信息写在标签里"的离线版。等 wrangler 登录后，可以升级成服务端版：
- 网址变成 `everybeloved.com/p/7xK2m`（短）
- 支持**上传真实照片**、多人协作补充、纪念日提醒
- 标签不用重写，只需把网址指向新页面
